# Native financial workbench

This distribution reuses the native YuChao frontend HTML, CSS, chart rendering and watchlist UI from `/Users/neo/workspace/yuchao/frontend` (read-only source snapshot, 2026-11-06). YuChao is licensed under GNU AGPL v3; the complete license is distributed in LICENSE. Retain original copyright notices. FinRove changes provide unified session RPC, user-scoped storage, and remove private calculations and legacy authentication. Public indicator calculations retain their ordinary technical-analysis identity. NEO protected indicators are unavailable until a server output contract is connected.

Source SHA-256 hashes for every reused input are recorded in SOURCE-HASHES.json. No proprietary calculation modules, old authentication, SSE, or old synchronization implementation are distributed.
